System architecture

How the valuation works.

The system combines structured vehicle information, machine learning and AI-assisted market analysis.

01

Car Details

The user provides information about the vehicle, such as its brand, model, year, kilometres driven, transmission, ownership and fuel type.

02

Preprocessing

The vehicle data is passed through the trained preprocessing pipeline so that the input has the same representation used during model training.

03A

Model A — Random Forest

The machine-learning model uses historical training data to estimate the vehicle's price.

03B

Model B — Market AI

The market-analysis path uses AI-assisted reasoning and market evidence to produce a second valuation perspective.

04

Comparison

The application presents the two estimates side by side so the user can understand how the valuation approaches differ.

05

Price Insight

The final interface presents the valuation information in a clear, human-readable form.
