MODEL A

RANDOM FOREST

Why preprocessing matters

The deployed application reuses the saved preprocessing pipeline from training rather than manually recreating the transformations in Django.

Training: data → preprocessing → model

Prediction: user input → saved preprocessing → model

MODEL B

AI + Internet Market Model

GEMINI + SEARCH

Model B is an AI-assisted market research pipeline. Instead of relying only on historical training data, it analyzes current Indian used-car market evidence.

User Input Same vehicle details
↓
Gemini AI Market analysis
↓
Market Evidence Current web/search information
↓
Model B Price Market-informed estimate

SEARCH / FALLBACK PIPELINE

Gemini → Market Search → Tavily fallback → Evidence

When the primary search path is unavailable, the project can use Tavily to obtain current market evidence for the Model B analysis.

What Model B looks at

  • Vehicle identity and specifications
  • Current used-car market evidence
  • Comparable market listings
  • Market context
  • Evidence gathered from search

What it produces

  • Estimated market price
  • Confidence information
  • Search method
  • Market reasoning
  • Supporting evidence / sources

AIML LEARNING

Why use two approaches?

Model A demonstrates supervised Machine Learning using a trained regression model. Model B demonstrates how an AI system can combine language-model reasoning with current market evidence.

Model A Learns patterns from historical training data.
Model B Uses AI reasoning and current market evidence.
Comparison Shows how historical ML estimation differs from market-informed valuation.
